# Silent Review 1.0.0 验收范围

本轮按用户优先级完成 P0、P1、P2，并保留 V12 女仆动画。

| 优先级 | 能力 | 验收重点 |
| --- | --- | --- |
| P0-1 | 多 Git 根 | 手动识别全部已登记仓库；提交回调处理各实际变化的根；单根失败不阻断其他根；逐仓库报告和批次汇总可追溯 |
| P0-2 | 报告处理 | 确认、采纳、关闭入口；时间、操作者、备注和历次操作持久化；关闭不删除；人工确认不改写 AI 的执行结果 |
| P1-1 | 面板切换 | 点击小人展开/收起，面板按钮可收起；其他明确的“查看报告”入口继续只展开 |
| P1-2 | 四边拖动 | 拖出顶部/左侧夹紧到该边，不把负坐标当默认位置；四边同等吸附；右下锚点随窗口变化 |
| P1-3 | 审查范围 | 显示真实仓库、冻结提交、文件和适用规则；按文件纳入/排除即时计数；冻结差异对比；请求和报告反映选择；提交变化要求刷新 |
| P2-1 | Key 状态 | 不回显秘密；按接口查询已配置状态；后台读写、写后回读；失败不清空输入或部分提交设置；留空保留旧值 |
| P2-2 | 首次配置 | 可创建可编辑的默认规则模板，已存在文件不覆盖；能检查规则并指引接口/授权/准备范围/执行 |
| P2-3 | 版本正式化 | 版本 1.0.0；安装范围与已验证环境明确；执行失败、未覆盖范围和模型不确定性明确表示 |

默认按工作区全部 Git 根处理。手动审查对象是已提交的快照，不是尚未提交的编辑或 IDEA 原生 diff 里未纳入的片段。原生提交窗口的纳入状态不会被插件擅自修改；自动提交后只检查该次成功提交的内容。

当前范围控件按文件选择。若后续明确需要逐个 diff 块选择，须单独定义部分文件的证据与覆盖语义，不能只改复选框显示。

## 验证约定

使用本机 IntelliJ IDEA Ultimate 2024.2.4 SDK/JBR 21 编译，运行现有回归测试及本轮新增测试，并执行插件结构验证。首次冷启动、真实 Key 和真实模型审查由安装后的验收覆盖；构建不会读取用户密码库或调用用户模型接口。

## 稳定性约定

- 新增功能不得修改用户源码、自动推送或阻塞提交。
- 无规则、取消、单仓库错误、部分覆盖不能伪装成审查通过。
- 审查根、提交、纳入范围和报告处理操作可追溯。
- 旧报告继续可读，凭据仍使用原项目和接口地址的存储命名空间。
- 支持的 IDE 构建范围与实际测试结果随安装包发布；不以“正式版”代替兼容性验证。
